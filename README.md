# ⚡ Vibe Coding — Hello World

> **"구현 디테일은 AI에게 맡기고, 당신은 비전과 설계에 집중하세요."**  
> 생각의 속도로 아이디어를 실체화하는 바이브 코더(Vibe Coder)를 위한 미니멀 모던 스타터 페이지입니다.

---

## 🌐 라이브 데모 (Live Demo)
- **웹사이트**: [https://jvibeschool.space/HTML/](https://jvibeschool.space/HTML/)

---

## ✨ 주요 기능

- **🕒 실시간 스마트 위젯**: 초 단위까지 부드럽게 흐르는 디지털 시계, 한국어 날짜 및 시스템/브라우저 기반 위치 정보(`📍 대한민국 서울`) 표시
- **🔮 Today's Vibe**: 바이브 코딩의 영감을 깨우는 큐레이션 명언 카드
- **⚡ 원클릭 바이브 부스터**: 직관적인 인터랙션과 클릭 카운터 피드백
- **🎨 모던 & 미니멀 UI**: 눈이 편안한 다크 테마, 글래스모피즘(Glassmorphism), 그리고 여백의 미를 살린 세련된 디자인
- **📦 제로 디펜던시 (Zero Dependency)**: 외부 라이브러리 설치 없이 `hello.html` 단일 파일만으로 즉시 구동

---

## 🛠 기술 스택

- **Core**: HTML5, Vanilla JavaScript (ES6+)
- **Styling**: Vanilla CSS3 (Custom Properties, Flexbox, Glassmorphism)
- **Fonts**: Inter, JetBrains Mono, Pretendard
- **Tools**: Git, GitHub CLI (`gh`)

---

## 🚀 로컬 실행 방법

별도의 빌드 과정이나 패키지 매니저 설치 없이 바로 실행할 수 있습니다.

```bash
# 1. 저장소 클론
git clone https://github.com/jvisualschool/HelloWorldv2.git
cd HelloWorldv2

# 2. 브라우저에서 바로 열기 (macOS 기준)
open hello.html
```

---

## 🐙 GitHub CLI (`gh`) 관리 및 배포

GitHub CLI를 사용하여 원격 저장소 생성 및 푸시를 손쉽게 진행할 수 있습니다.

```bash
# GitHub에 새 공개 저장소 생성 및 즉시 푸시
gh repo create HELLO --public --source=. --remote=origin --push

# 현재 저장소 브라우저에서 열기
gh repo view --web
```
